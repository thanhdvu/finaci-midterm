# finaci · 앱 요약 (v2 UI 기획)

**앱 이름:** finaci (피나시)　|　**부제:** 여러 통화로 이어지는 생활비 흐름을 계획하는 도우미　|　**카테고리:** 금융

| 안내문 2단계 항목 | 내용 |
|---|---|
| **목표** | 여러 통화와 반복 수입·지출을 한 흐름에서 확인하고, 사용자가 정한 날짜의 재무 목표가 현재 계획 안에서 가능한지 판단하도록 돕는다. 화면에서는 현재 잔액과 예정 잔액을 구분하고, 계산에 포함한 항목과 가정을 보여준다. |
| **대상 사용자 (페르소나)** | **제품 대상:** 여러 국가·통화에 걸쳐 수입, 지출 또는 계좌를 관리하는 global netizens. **프로토타입 사례:** 한국에서 생활하며 베트남 원격 급여(VND), 한국 아르바이트 급여(KRW), 가족 지원금을 함께 고려하는 베트남 유학생. 이 사례는 구체적인 테스트 상황이며 제품 전체 대상을 제한하지 않는다. |
| **해결할 문제** | 사용자는 거래를 기록하는 데서 멈추지 않고, 이미 입력한 반복 수입·지출이 앞으로의 잔액과 기한이 있는 목표에 어떤 영향을 주는지 알고 싶다. Wallet iOS 5.7.5 관찰에서 사용자는 Outlook이 어렵고, Planned Payments를 반영한 미래 잔액을 이해하려면 기존 항목을 다시 입력하거나 직접 연결해야 했다고 보고했다. 공개 리뷰 R01–R20은 이 Outlook 문제를 직접 입증하지 않으므로 개인 경험과 리뷰 근거를 구분한다. |
| **v2 핵심 가치** | **“여러 통화의 현재 잔액과 이미 알려진 수입·지출을 날짜별 전망으로 연결해, 목표를 향한 다음 결정을 쉽게 한다.”** 사용자는 예측 날짜, 포함한 반복 항목, 환율 가정을 확인하고 필요하면 시나리오를 비교한다. 미리 정한 AI 응답으로 급여 지연 상황을 설명하는 UI를 시연하며, 실제 AI·은행 연결·저장·금융 계산은 구현하지 않는다. |

**프로토타입 성공 기준:** 사용자가 한 화면 흐름에서 (1) 현재 잔액과 예상 잔액을 구분하고, (2) 전망에 들어간 예정 수입·지출과 날짜를 확인하며, (3) 빠진 변동 지출과 환율 가정을 알아차릴 수 있다.

**근거 수준:** 제품 대상과 가치 제안은 학생이 제시하고 확인한 방향을 AI가 문장으로 정리했다. 구체적 사례는 학생이 직접 설명한 경험이다. Wallet 기능은 iPhone 5.7.5 캡처와 사용자 보고를 바탕으로 하며, 다지역 리뷰는 `docs/wallet-review-notes.md`에 별도 기록했다. 본문은 W07 안내문의 한 페이지 요약 항목(목표·대상 사용자·문제·v2 핵심 가치)에 맞췄다. L035/L038/L039의 확인과 L046의 위임 보완을 반영했으며, 효과를 검증한 사용자 시험 결과로 제시하지 않는다.
