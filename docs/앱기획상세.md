# finaci 앱 요약과 주제 정의

2026-10-29 · 범위와 UX 방향은 사용자 선택을 반영했다. 한 페이지 요약은 `finaci-app-summary-onepage-ko.md`다.

## 앱의 목표

finaci(피나시)는 여러 국가와 통화에 걸쳐 수입·지출·계좌를 관리하는 사람을 위한 생활비 계획 도우미다. 현재 잔액과 이미 아는 예정 항목을 연결해 기한이 있는 계획을 이해하도록 돕는다. 카테고리는 금융이다.

v2의 핵심 가치는 기록한 반복 항목을 날짜별 전망의 근거로 다시 확인하는 경험이다. 통화 수를 늘리는 것 자체가 핵심은 아니다.

## 대상과 persona

전체 대상은 다국가·다중 통화 사용자다. 베트남-한국 조합은 대표 use case이며 제품의 국가 제한이 아니다. 다른 시장의 수요까지 검증한 것은 아니다. persona에는 사용자가 말한 사실만 사용했고 나이·소득·학교·소비 성향을 임의로 붙이지 않았다.

사용자는 VND 원격 급여, KRW 아르바이트 급여, 가족 지원금을 함께 보며 환율과 앞으로의 비용을 머릿속으로 연결해야 한다고 설명했다. 학비는 예시 목표다. 여행비·비상금 등 다른 목표도 제품 방향에 포함할 수 있다.

## 참조 앱과 우선 문제

Wallet은 이미 다중 통화·Dashboard·Statistics·Planned Payments·Budgets를 제공한다. 계좌별 카드와 중앙 +의 장점은 유지한다. 사용자는 Planned Payments를 Outlook에서 보려면 재입력했다고 확인했고 P07 주원칙/P06 보조를 선택했다.

Help Center의 iOS Goals 미지원은 플랫폼별 기능 차이다. R01–R20에는 Outlook/학비 목표의 직접 리뷰가 없다. 인접 리뷰와 개인 경험, 가설을 구분한다. 모든 과거 불만을 한 번에 고쳤다고 주장하지 않는다.

## 시연 범위

1. A 현금흐름 홈: 통화별 계좌와 현재/예상, 반영 항목, 보조 목표 카드.
2. B 일정 상세: 7일/30일/목표일까지와 예정 수입·지출. 기본값은 목표일까지다.
3. C 상황 비교: 2월25일 급여가 3월4일로 늦어 목표일2월28일을 넘는 고정 예시.
4. D 빠른 기록: 지출/수입/이체, 통화·계좌·분류·날짜를 보여 주며 저장하지 않는다.

로컬 json-server GET, 기본 Flutter 위젯과 화면 전환만 구현한다. 실제 환율 변환·잔액 계산·은행 연결·로그인·결제·영구 저장·AI API는 없다. 예상 결과와 AI 설명은 미리 작성한 예시다.
