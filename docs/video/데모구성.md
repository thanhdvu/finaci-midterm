# 60초 데모 구성

Flutter 실행 화면을 녹화하고 구간을 편집했다. 자막은 한국어다. 데이터는 고정 예시이며 실제 금융 계산·저장·AI 호출은 하지 않는다.

| 시간 | 확인할 내용 |
|---|---|
| 00–03초 | 로딩: GET 응답을 기다리는 표시 |
| 03–08초 | 오류 안내와 다시 시도 버튼 |
| 08–11초 | 다시 시도 후 정상 GET 데이터 표시 |
| 11–15초 | 전체 데이터가 없을 때의 빈 상태 |
| 15–22초 | A: 현재 잔액과 예상 흐름 |
| 22–29초 | B: 목표일까지의 예정 항목 |
| 29–33초 | 7일 필터에 해당 항목이 없는 상태 |
| 33–41초 | C: 목표일 뒤로 늦는 급여의 고정 비교 |
| 41–48초 | D: 중앙 +의 빠른 기록과 금액 입력 |
| 48–52초 | 실제 저장을 하지 않는 데모 안내 |
| 52–60초 | 1280px에서 달라지는 배치 |

로딩·오류·전체 빈 상태는 녹화 도구에서 GET 응답 지연·503·빈 배열을 주어 재현했다. 앱의 실제 상태 위젯을 촬영했으며 서비스 장애나 실제 개인정보를 사용한 결과가 아니다. 정상 구간과 재시도 성공은 로컬 읽기 전용 json-server의 데이터를 사용한다. 넓은 화면은 웹 viewport 검증이며 native desktop 앱 실행 증거는 아니다.
